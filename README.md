# MetagenomicsBench

**Benchmarking metagenomics**

This public subset contains four evals, their prompt/vocabulary files, and agent trajectory examples. MetagenomicsBench tests whether AI agents can analyze and interpret metagenomic data across core domains of the field, including microbial community structure, host–microbiome associations, microbial function, longitudinal dynamics, and microbiome interventions.
